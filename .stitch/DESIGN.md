# PetCare Design System

## 1. Overview
A high-converting, action-first design system optimized for a pet supply e-commerce platform. It balances playfulness (vibrant colors, cute elements) with clean, modern conversion-driven layouts.

## 2. Core Tokens
- **Primary Color:** #F4D35E (Solid yellow, used for hero backgrounds, key accents, and prominent CTAs)
- **Secondary Colors:** Clean white (#FFFFFF), dark text (#1A1A1A)
- **Typography:** Modern sans-serif (Inter or similar), clean and highly legible
- **Shape / Roundness:** Rounded corners for a friendly, approachable feel
- **Theme:** Light mode default

## 3. Component Styles
- **Buttons:** High contrast, clear calls to action. Primary buttons should be prominent and inviting.
- **Cards:** Equal height, clean 1:1 image ratios, subtle hover effects (scale + shadow) to encourage interaction.
- **Navigation:** Clean, intuitive, with quick access to cart and search.

## 4. UI Best Practices
- High visual hierarchy: Headings should be bold and large (e.g., Hero Headline 60px).
- Ample whitespace to let products stand out.
- Micro-interactions on hover (especially for product cards and categories).

## 5. Design System Notes for Stitch Generation
**DESIGN SYSTEM (REQUIRED):**
- **Theme:** Light mode
- **Primary Color:** #F4D35E
- **Typography:** Inter (or similar modern sans-serif)
- **Corner Style:** Rounded (friendly, approachable)
- **Aesthetic:** Modern, clean, "action-first" e-commerce. High contrast, vibrant hero sections, equal-height product cards with 1:1 images, subtle hover effects (scale + shadow).
